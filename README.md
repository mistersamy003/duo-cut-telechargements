# Duo Cut — téléchargement

Duo Cut est un éditeur vidéo personnel qui fonctionne entièrement sur votre ordinateur.

## Installer (Windows 10 ou 11)

1. **[Télécharger Duo Cut](https://github.com/mistersamy003/duo-cut-telechargements/releases/latest/download/DuoCut-Installation.exe)** (environ 180 Mo).
2. Ouvrir le fichier. Windows peut afficher « Windows a protégé votre ordinateur » (l'installeur n'est pas signé) : cliquer sur **Informations complémentaires**, puis **Exécuter quand même**.
3. Suivre l'installation (aucun droit administrateur demandé), puis ouvrir **Duo Cut** depuis le Bureau ou le menu Démarrer.
4. Au premier lancement, créer son compte (prénom + code d'au moins 10 caractères).

## Mises à jour

Rien à faire : quand une nouvelle version sort, un bouton **Mise à jour** apparaît en haut de Duo Cut. Un clic suffit, vos projets sont conservés.

## Vos fichiers

- Programme : `%LOCALAPPDATA%\Programs\Duo Cut`
- Projets, médias, exports : `%LOCALAPPDATA%\Duo Cut\data`

Ce dépôt ne contient que les installeurs ; le code source est privé. Licences des composants : voir l'écran « À lire » de l'installeur (Remotion est gratuit pour les particuliers et les entreprises de 3 personnes au plus).
